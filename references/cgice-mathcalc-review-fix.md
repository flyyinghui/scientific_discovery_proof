# 数学计算准确性专项评审（MathCalc Review）的 P0 数值修正

审稿类型：把论文里所有「具体数学计算结论」逐条提取、独立重算（Python + 手工代数），
区分「定义性算术」（恒等式）与「承载物理论断的数值」（预测值）。实测 CGICE V9.1
（2026-08-18）：14 项恒等式全对，但 4 项承载预测的数值 P0 错误——规律是
**凡是"由定义推出来的数"都对，凡是"用来支撑物理论断的数"几乎都有问题**。

## 四类 P0 数值错误（复现频发）

### 1. 相空间体积的「维度 vs 能量标度指数」混淆
- 症状：`N_e = (70/6)·ln(1+10⁶) ≈ 161`，声称 70 维相空间 → 指数用 70。
- 根因：2n 维相空间体积 ∝ E^n（能量标度指数是 n=35），不是 ∝ E^(2n)。
  70 维谐振子 Vol ∝ E^(70/2) = E^35。
- 修正：`N_e = (35/6)·ln(1+10⁶) ≈ 80.6`。检查法：问「体积对 E 的幂次是相空间维度，还是维度的一半？」

### 2. 单圈 RG 分离变量积分丢系数 2
- 症状：`dg/dlnμ = b₀g³/8π²` 给出解 `g = g₀/√(1 - b₀g₀²/(8π²)·ln)`。
- 根因：∫g⁻³dg = -½g⁻²，-½ 使分母系数翻倍 → 正确解分母是 **4π²** 不是 8π²。
- 修正：`g = g₀/√(1 - b₀g₀²/(4π²)·ln)`。数值随之变（g_TC(Λ_ν): 0.27→0.21）。

### 3. Landau 极点符号错误（红外 vs 紫外方向倒置）
- 症状：极点位置写成 `μ = M·exp(-8π²/(b₀g₀²))` 且断言在红外 ~10⁴ GeV。
- 根因：极点满足分母=0 → `ln(μ/M) = +4π²/(b₀g₀²)`（正号）。b₀>0 理论红外自由，
  极点必在紫外。
- 修正：`μ_Landau = M_GUT·exp(+4π²/(b₀g₀²)) ≈ 10²² GeV`（紫外）。连带后果：微扰流在
  低能端可靠、向红外减小，**无法**到达 FRG 强耦合定点——诚实标为「需要非微扰机制的开放问题」。

### 4. 临界耦合标度 μ_crit 公式非标准 + 量级崩坏
- 症状：`μ_crit = M·exp(-8π²/g·(1-1/g_crit))` 缺 1/b₀ 因子，算出 10⁻⁹ eV。
- 修正：`μ_crit = M·exp[(4π²/b₀)(1/g₀² - 1/g_crit²)]`。b₀=12,g₀=0.5,g_crit=2 →
  μ_crit ≈ 4.6×10²¹ GeV（紫外），与低能中微子凝聚无关。

## P1/P2 诚实声明（同样必改）

- **KLS-Lambda 对偶**：`Λ_CC ∝ λ_⊥·M_Pl²` 量纲 [M]²（缺 M_Pl²），未定比例因子实为
  ~10⁻¹²² 非 O(1)。删「解决 122 量级鸿沟」，改「几何动机 + 显式微调因子」。
- **Betti 数**：P(t)=(1+t²)⁵(1+t⁴)⁵ 展开 b₄=15、b₆=35（非 C(5,k)=10，忽略了 (1+t⁴)⁵ 交叉项）。
- **DM:baryon 5.47**：0.46% 嬗变只给 5/0.9954≈5.02，5.47 是观测值 Ω_c/Ω_b 反推（循环论证）。
- **H₀t₀=0.9497**：平直 ΛCDM 用 asinh 非 ln，Ω_DE=0.682→0.9484；0.9497 是 H₀×t₀ 反推值。
- **流形定性**：SL(6,C)/SU(3,3) 是伪黎曼（不定号）对称空间，非黎曼；黎曼版本是 SL(6,C)/SU(6)。

## 执行顺序

1. 读审稿 → 独立 Python 重算核实每个数值（不盲信审稿人算术，见 skill Pitfall 40）。
2. MD 逐项改（P0 数值 + P1/P2 诚实声明），每处加 `[2026-08-18 修正]` 标注。
3. Lean 同步（只改明确编码的数值，如 N_e 161.18→80.59、70/6→35/6），编译 0 sorry。
4. DOCX 同步：python-docx 的 `p.text` **读不到 OMML 公式里的数值**，只能改文本段落
   + 插入「计算修正说明」段落引用 MD 为权威。
5. 残留检查用**普通字符串 count**（`txt.count('161')`），不用正则（LaTeX `\p` 会 bad escape）。
   注意排除故意保留的旧值引用（"原160.3/161"、"非0.9497"）与 arXiv 编号。
6. 同步 SL6C 统一框架文档的对应参数（N_e/g_TC/Landau/DM:baryon/H₀t₀），
   不变项（g_TC(FRG)=2.60、g_TC²=24π²/35）确认不误伤。
7. 全局 `txt.replace("N_e=160", "N_e=80.6")` 会**误伤 "N_e=160.3"** 变 "80.6.3"——
   先替换带上下文的完整 token，再单独处理带小数后缀的变体。
