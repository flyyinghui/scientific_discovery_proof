# 物理论文数值计算审查模式（Calculation Audit Patterns）

**固化来源**：CGICE V9.1 MathCalc 计算审查（2026-08-18），全部数值经 Python 独立重算核实。
**适用场景**：审稿报告声称论文"核心数值算错了"时——不是公理/定理问题，而是微分积分/相空间体积/符号约定本身的代数错误。

## 判别原则（审稿报告原话，最核心的洞察）

> **凡是"由定义推出来的数"都对；凡是"用来支撑物理论断的数"几乎都有问题。**

- ✅ **定义性算术恒等式**（τ=6π/35、α 倒数、Λ=1225/18π、ln 值、5.29³=148）——这类是纯代换，通常对。
- ❌ **承载物理论断的核心数值**（N_e、g_TC 流、Landau 极点、μ_crit、H₀t₀）——这类涉及积分/标度律/符号约定，几乎必查出错。

**修审稿时先分类**：审稿列的 N 个问题里，哪些是"恒等式"（跳过）、哪些是"核心数值"（独立重算核实）。

## 4 类 P0 数值错误模式（可复用的检测 + 修正公式）

### 1. 标度指数混淆（相空间体积 → e-fold 数）
- **错误**：N_e = (70/6)·ln(1+10⁶) = 161，把"相空间维度 70"当"能量标度指数"。
- **正确**：2n 维相空间（n 维构型空间）Vol ∝ E^n（谐振子 H≤E 围成体积 ∝ E^n，非 E^{2n}）。此处 n=35，故 N_e = (35/6)·ln = 80.6。
- **检测**：看到 `(dim_TM / 6)·ln(...)` 就要查——e-fold 数应正比于**构型空间维数**（= 相空间维数/2），不是相空间维数本身。

### 2. 微分方程解丢系数 2（分离变量积分）
- **错误**：dg/dlnμ = b₀g³/8π² 的解分母写 8π²。
- **正确**：∫g⁻³dg 得 -½[g⁻²]，系数 2 移到分母 → 解是 g = g₀/√(1 - b₀g₀²/(4π²)·ln)，分母 **4π²** 非 8π²。
- **检测**：任何 `g³/8π² → 解分母 8π²` 的自洽性——分离变量后 ∫g⁻³dg 的反导数是 -1/(2g²)，那个 ½ 会翻倍分母系数。

### 3. 符号错误（Landau 极点 IR/UV 方向）
- **错误**：b₀>0 却声称极点在红外（低能）。
- **正确**：b₀>0 ⇒ 红外自由（IR-free，g 随 μ↓ 减小），极点满足 ln(μ/M)=+4π²/(b₀g₀²)（**正号**，紫外）。μ_Landau = M·e^{+...} ≈ 10²² GeV。
- **检测**：先看 β 函数符号——b₀>0 必是 IR-free，极点必在 UV；论文若说"极点截断红外流"就是符号倒置。

### 4. 公式缺因子（临界标度缺 1/b₀）
- **错误**：μ_crit = M·exp(-8π²/g·(1-1/g_crit))，缺 1/b₀ 因子且临界条件形式错。
- **正确**：μ_crit = M·exp[4π²/b₀·(1/g₀² - 1/g_crit²)]（由正确 RG 解反解）。
- **检测**：临界标度公式必须含 b₀（β 函数系数）；缺 b₀ 的"临界公式"必是拼凑的。

## 修正流程（三文件同步）

1. **独立重算**：用 Python（`math`/`cmath`）对每个 P0 数值独立计算，确认审稿属实（勿盲信审稿人的算术，见 pitfall 40 的 bh_transmutation bound 教训）。
2. **MD 修正**：精确替换公式 + 值 + 加 `[P0-X FIX 2026-08-18]` 诚实声明（说明旧值错在哪、新值从哪来）。
3. **Lean 修正**：`def`/`axiom` 数值同步（如 `(70/6)→(35/6)`、`161.18→80.59`），编译验证 0 sorry。
4. **DOCX 修正**：⚠️ **DOCX 数学公式数值在 OMML XML 里，`python-docx` 的 `p.text` 提取不到**——逐个改 OMML 很繁琐。务实方案：(a) 改**文本段落**（非公式）里的关键表述；(b) 在摘要后插入 `[CALCULATION CORRECTION]` 说明段落，列全部修正 + 声明"公式以 MD 为准"。
5. **残留扫描**：grep 全部旧值（161、0.27、10⁴ GeV、2.33、10⁻⁹ eV），确认 0 残留。

## 物理后果的诚实重述（关键）

修正 P0-3/P0-5 后往往暴露**理论物理后果**：b₀=12>0 ⇒ 理论红外自由，g_TC 向低能减小（0.21 弱耦合），无法自然到达 FRG 强耦合值 2.60。**正确处理是诚实标注为"需要非微扰机制的开放问题"，而不是篡改符号硬凑结论**。这正是审稿报告要求的"诚实面对计算错误而非学术粉饰"。
