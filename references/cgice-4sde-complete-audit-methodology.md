# CGICE 4-SDE 完整审计方法论

## 四步检测法

用于检测论文是否真正实现了CGICE动力学（而非仅"声明"）：

### Step 1: 方程存在性检查

对比论文声称 vs 实际代码/md/lean:

```
grep -i "CGICE-1\|Langevin\|dχ/dτ" *.md *.lean
grep -i "CGICE-2\|Riccati\|dA/dτ" *.md *.lean
grep -i "CGICE-3\|拓扑流\|topological\|J^k" *.md *.lean
grep -i "CGICE-4\|闭合\|closure\|∮dS" *.md *.lean
```

### Step 2: 区分声明与实现

对每个匹配到的方程:
- **声明**: 仅在注释/头文件中提及，代码中无对应变量/函数
- **类型声明**: 有结构体定义 (如 `CGICE_System`) 但无求解代码
- **部分实现**: 有简化版本 (如仅beta函数投影)
- **完整实现**: 有数值求解代码

### Step 3: FRG流可实现性验证

```
独立计算: g²(目标标度) vs g_TC²(定点)
若 g²/g_TC² < 0.1 → 定点是"目标"非"达到"
```

V63案例: g²(M_R)≈0.01, g_TC²≈6.77, gap因子~677 → 定点未达到

### Step 4: 因果连接测试

删除CGICE引用后，核心结果是否改变？
- 若 seesaw m_ν 计算结果不变 → CGICE与核心结果无因果关系
- 若 GW频率仍为硬编码值 → CGICE不驱动GW预测
