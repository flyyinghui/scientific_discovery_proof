# CGICE 2026-08-18 数学计算审查 — 数值错误模式与修正清单

来源：`Hybrid_Review_CGICE_V91_MathCalc_20260818.md` + `CGICE论文计算审查核实20260818.md`（灰因斯坦 Grey Turing 评审），经 Python 独立重算核实，跨 12 文件（CGICE×3 + SL6C 框架 + V16×3 + V63×3 + V17×2）同步。

## 核心结论（一句话）

"定义性算术全部正确，承载物理论断的数值几乎全错"——凡是"由定义推出来的数"（τ=6π/35、Λ=1225/18π、α 倒数）都对；凡是"用来支撑物理论断的数"（N_e、g_TC 流、Landau 极点、μ_crit）都有错。

## 六类数值错误模式（可复用的审查清单）

### 1. N_e 相空间体积 E 标度指数陷阱（P0）

- **错误**：70 维相空间（dim T*M = 70），论文用 N_e = (70/6)·ln(1+10⁶) ≈ 161。
- **正确**：能量标度指数是 **35** 不是 70。70 维相空间体积 Vol ∝ E^(70/2) = E^35（70 维谐振子，n=35 构型维）。所以 N_e = (35/6)·ln(1+10⁶) ≈ **80.6**。
- **检测**：相空间总维度 dim(T*M) ≠ 能量标度指数。对 n 维构型空间，2n 维相空间 Vol ∝ E^n。
- **影响面**：摘要 + 正文 + 结论 + 附录 + 表格 + Lean 的 N_e 定义全要改。

### 2. 单圈 RG 积分因子 2（P0）

- **错误**：dg/dlnμ = b₀g³/(8π²) 的"解"分母写 8π²。
- **正确**：分离变量积分 ∫g⁻³dg = ∫(b₀/8π²)dlnμ 得 -½[g⁻²] = (b₀/8π²)ln，移项后分母是 **4π²**（不是 8π²）。
- **数值**：g_TC(Λ_ν) = 0.5/√(1+2.33) ≈ 0.27（错）→ 0.5/√(1+4.66) ≈ **0.21**（对）。
- **陷阱**：改分母后根号内的中间值也要改（2.33→4.66），否则"改了公式没改结果"。

### 3. Landau 极点方向符号（P0）——跨论文符号约定差异

- **CGICE/V17 约定**：dg/dlnμ = +b₀g³/8π²（正号）→ IR 自由 → Landau 极点在 **紫外** μ = M_GUT·exp(+4π²/(b₀g₀²)) ≈ 10²² GeV。
- **V63 约定**：β(g) = -b₀g³/(4π)²（标准 QCD 负号）→ 渐近自由 → Landau 极点在 **红外** μ ≈ 7.4×10⁴ GeV。
- **关键陷阱**：**同一物理量（Landau 极点方向）在两篇论文间因 β 函数符号约定不同而相反，这是 P1 跨论文不一致，不是算术错误。** 不要强行归一——诚实标注"符号约定待统一"即可。物理上标准 QCD 约定（负号，渐近自由）是对的；CGICE 正号约定是非标准的。
- **附带陷阱**：CGICE 的 Λ_ν≈0.05 eV vs V63 的 M_R≈10¹³ GeV 是不同物理尺度，g_TC 单圈值不同（0.21 vs 0.55-0.58）是合理的，不是矛盾。

### 4. μ_crit 公式缺 1/b₀ + 临界条件错误（P0）

- **错误**：μ_crit = M·exp(-8π²/g·(1-1/g_crit))，缺 1/b₀，临界形式也错。
- **正确**：μ_crit = M·exp(4π²/b₀·(1/g₀² - 1/g_crit²)) ≈ 4.6×10²¹ GeV（紫外）。
- **教训**：临界耦合标度公式必须从正确的 RG 解反解，不能凭"物理直觉"写。

### 5. DM:baryon 5.47 循环论证（P1）

- **错误**：声称"0.46% 重子黑洞嬗变 → 5.00 变 5.47"。
- **正确**：0.46% 嬗变只给 5.02 = 5.00/0.9954；要 5.47 需 8.59% 亏损率。5.47 是 Planck 观测值 Ω_c/Ω_b≈5.44，0.46% 是从 5.47 反推的。
- **检测**：`5.47/5.00 = 1.094`，但 `1/(1-0.0046) = 1.0046`，两者不匹配即循环论证。

### 6. |ρ|² = 35 归一化（P0-4，已解决）

- 标准 trace-form |ρ|² = 70/4 = 35/2 = 17.5；doubled normalization B=2·Tr 下 = 35。
- **正确处理**（V63/V17 已做）：显式声明归一化 + `factor2_bridge : 2·(35/2) = 35` 定理桥接。
