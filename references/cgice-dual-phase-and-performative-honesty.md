## 一、对称空间双相角色分工（用户纠正，重要）

**用户纠正（2026-08-21）**：修复 SL(6,C) 对称空间混用时，**不要"全文统一"到一个 coset**——我曾把 12 处 SU(3,3) 全部统一成 SU(6)，这是错的。正确做法是**双相角色分工**（dual-phase role division）：

| 角色 | coset | 位置 | 物理意义 |
|------|-------|------|---------|
| IR 物理相（时空分裂态）| SL(6,C)/SU(3,3) | A1、§2.5、§2.6、§4.6、附录 A.1（+ §1/§4 引言、§4.3）| 动力学系统、相空间、拓扑流、状态变量表 |
| 谱分析数学流形 | SL(6,C)/SU(6) | §2.1、§4.1、§7.2（+ 摘要、§2.3、§2.7、A3）| Laplace–Beltrami / Witten Laplacian 谱、Λ_CC |

并在 §2.1 新增一段 **实截面锁定 / Wick 旋转映射**（框架 §6.1 方向）：
- (i) UV 欧几里得相 SL(6,C)/SU(6)（谱分析数学流形）— 正定 Riemann，谱分析在此进行，谱下界 |ρ|²=35
- (ii) IR 分裂相 SL(6,C)/SU(3,3)（IR 物理相）— 非紧实形式，(1+2+3) 时空分解（A16），三连续协变微分系统（A20-A22）
- (iii) 实截面锁定 — Wick 旋转把 SU(6) 上的 UV 谱隙结果（λ_∥=35、λ_⊥=35/3）解析延拓到 SU(3,3) 的 IR 宇宙学，不混淆两个流形

**判定规则**：跨论文 coset 空间不一致时，先判断每个位置是"物理相"（动力学/相空间/拓扑流 → SU(3,3)）还是"谱分析"（Laplacian/Witten 谱/Λ_CC → SU(6)），用角色分工而非盲目统一。这与"跨论文符号约定差异不强行归一"（β 符号约定）是同一原则。

## 三、v4-pro 校核误判案例（模型记忆不可靠）

v4-pro 判 `s1_lambda_perp_eq_35_over_3` 用 `mul_right_inj'` 方向错误（✗），但该定理实测编译通过（`lake env lean` exit 0）。真相：mathlib 4.34 真实签名是

```
lemma mul_right_inj' (ha : a ≠ 0) : a * b = a * c ↔ b = c
```

即**左乘**可注入（`a*b = a*c`），而 v4-pro 记成了右乘（`a*c = b*c`）。**教训**：模型对 mathlib 签名的记忆可能错，模型判"✗"时先用 `scripts/mathlib_api_lookup.py` 检索源码核实签名，再接受结论。这与"检索当前源码比模型记忆可靠"同一原则——检索模块在本案例中救回了正确结论。
