# 审稿意见客观性评估方法论

## 适用场景

当收到严格的同行评审意见时，在逐条修改之前，先做**事实核查分类**：

1. 逐条提取审稿人的数值声明
2. 独立重算每个数值
3. 将每条指控分为三类:
   - **客观有效**: 数值/逻辑正确 → 纳入修改清单
   - **基于过期版本**: 指控针对已修复的旧值 → 驳回，注明修复日期
   - **事实错误**: 审稿人自身计算/前提错误 → 驳回，附独立验证数据

## 四步评估法

### Step 1: 提取数值声明
从审稿文本中提取所有带等号的数值声明，记录: 声明值、使用的参数、推导路径

### Step 2: 独立重算
用 Python/execute_code 逐条重算，不信任任何一方的数值

### Step 3: 交叉验证
将重算结果与论文 DOCX (最新版) 和 Lean 文件中的值三方比对

### Step 4: 分类输出
生成:
- 客观问题清单 (P0/P1/P2, 带修改建议)
- 驳回清单 (含驳回理由和证据)
- 优先级路线图 (Phase 1→2→3)

## 典型案例: V63/V16/V17 三论文混合审阅 (2026-08-07)

15条指控中: 11条客观有效 / 3条基于过期版本 / 1条事实错误

**事实错误案例**: 审稿人 V63 P0-2 声称 M_R = 0.480 × 10^16 = 4.8×10^15 GeV 矛盾。
独立验证: V63 实际使用 φ₀ = 1.67×10^14 GeV (seesaw 冷凝尺度)，
审稿人误用了 CW UV 边界 φ₀ ~ 10^16 GeV。这是两个不同物理尺度，
偏差 60×。驳回。

**过期版本案例**: 审稿人声称 V63/V17 g_TC=0.5 与 g_TC=2.60 矛盾。
独立验证: 2026-08-06 修复后三论文统一使用 g_TC=2.60，
grep 确认 DOCX+Lean 零残留 0.5。驳回。
