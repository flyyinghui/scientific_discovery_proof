# 修订 20260819 四个 P0 修复 + 朗之万 EEM 重构（可复用模式）

## 四个 P0 修复模式

### P0-1 量纲错误：|ρ|² 误代入 |ρ| 位置（101 阶误差）

**症状**：衰减公式 exp(−2|ρ|ΔR) 里把 Weyl 向量**范数平方** |ρ|²=35 直接代入**范数** |ρ|=√35≈5.916 的位置，得到 exp(−2×35×4.01)≈10⁻¹²²，但真实是 exp(−2×√35×4.01)≈2.5×10⁻²¹ —— 差 **101 个数量级**。

**检测**：对任何形如 exp(−2·X·t) 的指数衰减，独立重算 X 的量纲与物理含义。若 X 是谱隙/能量标度则合法；若 X 是范数/模长则须开方。

**修复（Fokker-Planck 协方差耗散）**：改用动力学耗散 A(τ)~A(0)·e^{−2λ_∥τ}，其中 λ_∥=|ρ|²=35 是**纵向谱隙**（合法出现在指数里），τ_c=4.01 是相变弛豫时间。静态测度截断（雅可比 J~e^{−2|ρ|ΔR}）彻底废除。

### P0-2 参数倒推伪装"无自由参数"

**症状**：ΔR=4.01 是凑 10⁻¹²² 的反推拟合，但论文宣称"无自由参数第一性原理"。

**修复**：诚实声明 τ_c=4.01 是**唯象标定**的相变弛豫时间 [honest-axiom]，撤回"no-free-parameter"声称。学术诚实 > 表面自洽。

### P0-3 循环论证（η 由 g* 倒推）

**症状**：η=2.06 由 g*=2.60 倒推，再声称 g* 由 η 决定——循环定义，无独立场论/几何支撑。

**修复（第一性原理切断）**：找代数几何不变量来源——
η_k = C₂(adj)·h^∨/dim(M) = 12×6/35 = 72/35 ≈ 2.057
g* = √(4π²|η_k|/b₀) = √(24π²/35) ≈ 2.6015

**通用规律**：当一个量由目标值倒推时，找它的**李代数不变量**（C₂、h^∨、dim、Casimir）或**谱几何**来源，切成第一性原理。C₂(adj)=12 ≠ h^∨=6（两个不变量，别混淆）。

### P0-4 逻辑锁死（公理强制常数）

**症状**：axiom a10_alpha_relation 强制 Λ_CC=35/(3α)=常数 21.66，与动态演化矛盾（内部逻辑锁死）。

**修复**：`axiom` 降级为 `def ... : Prop := ...`（命题定义），引用它的 lemma 加前提 `(hrel : a10_alpha_relation t)`。切断全局锁死，保留条件受限使用。

## 朗之万 EEM 重构（2026-08-19 第二轮）

### EEM 随机展开（平直噪声 → 流形严格化）

原 CGICE-1 在局部坐标加欧氏噪声（破坏等距群对称性，轨迹逃逸流形）。重构：
- 正交标架丛 O(M) 水平提升，Stratonovich SDE：dU_τ = Ṽ dτ + √(2/β)Σ H_i∘dW^i，χ_τ=π(U_τ)
- Bochner 等价 ΣH_i²=Δ_M → 投影生成元 L_M = V·∇ + (1/β)Δ_M
- Stratonovich（非 Itô）保规范对称性

Lean 落地：`a23_bochner_horizontal_laplacian`（honest-axiom，Mathlib 流形框架未完整形式化的占位符）+ `t5_eem_generator_equivalence`（rfl 真推理链）。

### 平行规范 → 迈斯纳凝聚

`aJ_symm_gauge`（A^μJ^ν=A^νJ^μ 平行假设，缺乏物理内涵）→ `a25_meissner_condensation`（拓扑信息超导相变，阿贝尔投影，A^μJ^ν 对称是凝聚相宏观涌现）。数学形式不变（还是对称等式），语义升级为相变推论。

### S₈ 微扰论（"not addressed" → 机制）

横向谱隙 λ_⊥=35/3 充当动量空间红外/紫外截止，诱导拓扑粘滞抑制非线性密度级联，缓解 S₈ 张力（Planck 0.832 vs KiDS/DES 0.76）。
